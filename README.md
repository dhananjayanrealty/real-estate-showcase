# Real Estate Land Showcase Website

A complete real estate property showcase website with admin panel for land brokers.

## Features
- Property listing with search & filter
- Property details with photos & videos
- Admin panel for content management
- Image upload to ImgBB
- Video upload to Cloudinary
- Mobile-friendly responsive design
- Direct call-to-action for brokers

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Node.js, Express.js
- Database: SQLite
- Media Storage: ImgBB (images), Cloudinary (videos)
